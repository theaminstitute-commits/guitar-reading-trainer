GUITAR READING TRAINER - Linux Mint / Ubuntu
============================================

Install (no sudo needed):
  1. Unzip this folder anywhere.
  2. Open a terminal in it and run:   sh install.sh
  3. Start "Guitar Reading Trainer" from the menu (Sound & Video, or Education).

Try without installing:   sh guitar-reading-trainer.sh

It opens in its own window when Chromium or Google Chrome is installed
(sudo apt install chromium). Otherwise it opens in Firefox. Works offline.
Your progress (melody length, counts) stays on this computer.

Remove:   sh uninstall.sh   (also deletes saved progress)
